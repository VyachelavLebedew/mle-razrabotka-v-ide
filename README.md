# mle-razrabotka-v-ide

1. DataFrameReporter

Класс предназначен для анализа датафрейма. Ожидаемый результат:

- количество строк;
- количество столбцов;
- количество дубликатов;
- доля дубликатов;
- информацию о пропущенных значениях;
- общие данные о датафрейме.

2. Установка

git clone https://github.com/VyachelavLebedew/mle-razrabotka-v-ide.git
cd mle-razrabotka-v-ide
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
pip install pandas

3. Запуск

python main.py
